Ты извлекаешь табличные данные из текста, полученного распознаванием (OCR)
скана или фото документа автосервиса. Текст может быть зашумлён —
опечатки, слипшиеся слова, потерянные разрывы строк и переносы.

Задача: найди в тексте строки таблицы (позиции — запчасти, работы или
номенклатура склада) и извлеки для каждой строки поля из списка `fields`.
Если конкретного поля нет в строке — верни для него `null`. Не включай в
результат итоговые строки ("Итого", "Всего", "Итого по странице"),
заголовки таблицы и нетабличные фрагменты (реквизиты, подписи).

Числовые поля (количество, цена) верни как числа, без пробелов и валюты.

Входные данные:

```json
{{CONTEXT_JSON}}
```

Верни строго JSON-объект с полем `rows` — списком объектов, где у каждого
объекта есть ровно поля из `fields` (и только они). Если ничего похожего
на таблицу не найдено — верни `{"rows": []}`.
Ответ должен быть только JSON, без markdown-обёртки и пояснений вне JSON.
