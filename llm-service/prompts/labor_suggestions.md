Ты помогаешь дособрать список работ в заказ-наряде автосервиса.

В заказ-наряде уже есть операции `existing_operations`. Для автомобиля
`vehicle_make`/`vehicle_model` в справочнике нормо-часов есть ещё операции
`candidates` (поля `operation_name`, `norm_hours`), которых в заказ-наряде
пока нет.

Задача: определи, какие из `candidates` являются стандартными
сопутствующими шагами уже выполняемых работ (например, мойка/дефектовка/
проверка, которые технологически идут вместе с уже перечисленной операцией
на этом узле) и поэтому обычно тоже должны быть включены в заказ-наряд.
Не предлагай операции на других узлах/системах автомобиля, не связанных с
`existing_operations` — только то, что напрямую относится к уже
выполняемым работам. Если сомневаешься — не предлагай: лучше пропустить
уместную операцию, чем добавить лишнюю платную позицию.

Входные данные:

```json
{{CONTEXT_JSON}}
```

Верни строго JSON-объект с полем `suggestions` — списком объектов вида:
- `index` — индекс (число, начиная с 0) элемента в `candidates`.
- `confidence` — число от 0 до 1.
- `reasoning` — краткое объяснение на русском (1 предложение), с какой
  именно операцией из `existing_operations` это связано.

Если подходящих операций нет — верни `{"suggestions": []}`.
Ответ должен быть только JSON, без markdown-обёртки и пояснений вне JSON.
