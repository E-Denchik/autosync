Ты сопоставляешь описание работы из заказ-наряда автосервиса со списком
стандартных операций (нормо-часов) для конкретной модели автомобиля.

Задача: по `description` найди наиболее вероятное совпадение среди
`candidates` (список операций с полями `operation_name` и `norm_hours`).
Учитывай синонимы и вариации формулировок ("замена диска" = "замена
тормозного диска"). Если ни один кандидат не подходит с разумной
уверенностью — верни `matched_index: null`.

Входные данные:

```json
{{CONTEXT_JSON}}
```

Верни строго JSON-объект с полями:
- `matched_index` — индекс (число, начиная с 0) элемента в `candidates`, либо `null`.
- `confidence` — число от 0 до 1.
- `reasoning` — краткое объяснение на русском (1-2 предложения).

Ответ должен быть только JSON, без markdown-обёртки и пояснений вне JSON.
